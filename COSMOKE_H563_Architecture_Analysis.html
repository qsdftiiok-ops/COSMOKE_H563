COSMOKE H563 Firmware Architecture & Technical Report

MCU: STM32H563ZIT6 @ 250MHz RTOS: Azure RTOS ThreadX Stack: NetX Duo (IPv4/UDP) ADC: ADS131M08 (24-bit 4kHz) DAC: DAC8564 (16-bit 100Hz)

01. System Overview (시스템 개요)

COSMOKE H563 펌웨어는 고성능 STM32H563ZIT6 마이크로컨트롤러를 기반으로 고정밀 2채널 전압/전류 센싱(총 4개 아날로그 채널) 및 실시간 아날로그 재전송(DAC8564), 고속 LAN UDP/UART 텔레메트리 송신을 수행하는 임베디드 매체 제어 시스템입니다.

High-Speed Sampling 4.0 kHz
ADS131M08 24-bit 델타-시그마 ADC를 통해 4000Hz 속도로 4채널 동시 샘플링 및 EXTI3 DRDY IRQ + DMA 자동 수신을 수행합니다.
Calibrated Analog Out 100 Hz
DAC8564 16-bit 4채널 DAC를 통해 필터링된 공학 단위 신호를 0.5V ~ 4.5V 실시간 정밀 아날로그 전압으로 재생성합니다.
Dual Telemetry Path UDP / UART
NetX Duo 기반 100Mbps Ethernet 브로드캐스트 UDP 송신과 ST-LINK VCP UART 직렬 출력을 10Hz 주기로 동시에 거울 출력합니다.

02. Hardware & Bus Topology (하드웨어 버스 토폴로지)

SPI1 버스를 ADS131M08 ADC와 DAC8564 DAC가 공동으로 사용합니다. CS(Chip Select) 핀을 개별 제어하며, ADC는 하드웨어 DRDY EXTI3 인터럽트에 의해 DMA 29바이트 프레임을 연속 수신하고, DAC는 블로킹/동기 전송 방식으로 제어됩니다.

03. ThreadX RTOS Structure (스레드 구조 및 우선순위)

Azure RTOS ThreadX 커널 상에서 3개의 주요 스레드 및 인터럽트 서비스 루틴(ISR)이 협력적으로 동작합니다. 우선순위 역전을 방지하고 실시간 결정성을 보장하도록 각 스레드의 우선순위가 정밀 조율되어 있습니다.

Execution Context Priority Period / Trigger Primary Responsibility
EXTI3_IRQHandler ISR High 4.0 kHz (250 μs) ADS131M08 DRDY 신호 하강에지 감지 및 SPI1 DMA 수신 트리거
NetX Duo IP Thread Priority 4 Event-Driven NetX Duo 프로토콜 스택(ARP, ICMP, UDP, IP) 내부 드라이버 처리
Application Thread Priority 5 100 Hz (10 ms) ADC 링버퍼 읽기, IIR 필터링, 공학 단위 변환, DAC8564 출현 및 텔레메트리 큐핑
LAN Telemetry Thread Priority 8 10 Hz (100 ms) NetX Duo UDP 패킷 생성 및 192.168.0.255:5000 브로드캐스트 전송

04. Deferred DRDY & SPI Lock Optimization (지연 DRDY 버스 제어)

기존 문제점 (SPI 버스 경합으로 인한 샘플 유실)
100Hz 주기로 DAC8564_WriteAll()이 실행될 때 SPI1 버스를 점유(s_bus_locked = true)합니다. 이때 4kHz ADC DRDY 인터럽트가 발생하면 기존 코드에서는 프레임을 즉시 버리고 dropped_frames++ 카운터를 증가시켰습니다.
개선된 해결책 (Deferred DRDY Pending Queue)
DAC 전송 중 DRDY 인터럽트가 발생하면 샘플을 버리는 대신 s_drdy_pending = true 플래그를 설정합니다. 이후 DAC 전송이 끝나고 ADS131M08_UnlockBus()가 호출되는 즉시 대기 중이던 ADC DMA 수신을 트리거하여 프레임 유실율 0%를 달성했습니다.
Core/Src/ads131m08.c — Deferred DRDY & Unlock Handling C11
/* EXTI3 DRDY Interrupt Handler */ void ADS131M08_OnDrdyInterrupt(void) { /* SPI 버스가 DAC에 의해 잠겨 있는 경우, 드랍하지 않고 펜딩으로 전환 */ if (s_bus_locked) { s_drdy_pending = true; return; } s_dma_busy = true; HAL_GPIO_WritePin(ADC_CS_N_GPIO_Port, ADC_CS_N_Pin, GPIO_PIN_RESET); HAL_SPI_TransmitReceive_DMA(s_spi, s_dma_tx, s_dma_rx, ADS131M08_FRAME_BYTES); } /* Bus Unlock & Deferred Trigger */ void ADS131M08_UnlockBus(void) { bool trigger_pending = false; uint32_t primask = EnterCritical(); s_bus_locked = false; if (s_drdy_pending && s_running && s_online && !s_dma_busy) { s_drdy_pending = false; s_dma_busy = true; trigger_pending = true; } ExitCritical(primask); if (trigger_pending) { HAL_GPIO_WritePin(ADC_CS_N_GPIO_Port, ADC_CS_N_Pin, GPIO_PIN_RESET); HAL_SPI_TransmitReceive_DMA(s_spi, s_dma_tx, s_dma_rx, ADS131M08_FRAME_BYTES); } }

05. Signal Calibration & Math Pipeline (신호 처리 공식)

수신된 24-bit Raw ADC 카운트 수치는 2의 보수 부호 확장 및 Calibration 매개변수를 거쳐 최종 공학 단위(A, V)로 변환된 후 1차 IIR LPF 필터를 적용받습니다.

1. ADC Volts = Raw_Counts × (1.200 V / (8388608 × PGA_GAIN))
2. Engineering Units = (ADC_Volts / Volts_Per_Unit) × Scale_Trim × Polarity + Offset_Units
3. Filtered_k = Filtered_(k-1) + α × (Units_k - Filtered_(k-1))
4. DAC Code = APP_DAC_CENTER_CODE (32768) + Normalized × APP_DAC_SPAN_CODE (26214)
리팩토링: APP_DAC_SPAN_CODE 상수 도입
기존 measurement.c 내부에 하드코딩되어 있던 26214.0f 상수를 app_config.h의 APP_DAC_SPAN_CODE 매크로 상수로 추출하여 설정 변경 및 코드 유지보수성을 극대화했습니다.
