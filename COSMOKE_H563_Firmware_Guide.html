03부팅과 실행 구조

  1. HAL 및 주변장치 초기화
    GPIO → GPDMA → I-Cache → SPI1 → Ethernet HAL → LED → USART3
  2. ThreadX 커널 진입
    MX_ThreadX_Init() → tx_kernel_enter()
  3. 정적 메모리 풀 생성
    Application용 TX pool 16 KB, NetX용 NX pool 48 KB
  4. 측정 Thread 생성
    App_Init() 후 App_Task() 반복, 1 tick 간격으로 휴면
  5. NetX 객체 생성
    Packet pool → IP → ARP/ICMP/UDP → DHCP → LAN telemetry Thread
  6. DHCP 주소 획득 후 송신
    링크와 IPv4 주소가 모두 준비된 경우에만 UDP datagram 전송

실시간 경로 우선 ADC EXTI/SPI DMA 계열 IRQ는 priority 0, Ethernet IRQ는 최종적으로 priority 5입니다. 네트워크 burst보다 ADC 획득 지연을 우선하도록 구성되어 있습니다.

04측정 데이터 흐름

ADC 획득 경로

  1. ADC_DRDY_N falling edge 발생
  2. EXTI ISR에서 30바이트 SPI DMA 시작
  3. DMA 완료 ISR에서 raw frame을 ring에 저장
  4. Measurement Thread가 ring을 비우며 CRC 확인

Ring은 128 slot이며 full/empty 구분 때문에 실제 최대 보관량은 127 frame, 약 31.75 ms입니다.

MAC 주소

STM32의 96-bit UID를 FNV 방식으로 혼합해 각 장비의 로컬 관리 unicast MAC을 생성합니다.

02:xx:xx:xx:xx:xx
│
└─ bit0 = 0  → unicast
   bit1 = 1  → locally administered

고정 MAC을 여러 보드에서 공유하지 않으므로 동일 LAN에 복수 장비를 연결할 수 있습니다.

07상태 플래그

플래그 계산기

체크박스를 선택하거나 16진수 값을 직접 입력하면 상태를 해석합니다.

VALID유효한 측정값이 포함되어 있습니다.
현재 상태와 누적 상태의 차이 LAN_LINK_DOWN, LAN_NO_ADDRESS, ADC_OFFLINE은 현재 상태입니다. 오류 카운터 기반 CRC/SPI/drop/DAC/LAN TX 플래그는 해당 초기화 주기에서 한 번이라도 오류가 발생하면 계속 표시될 수 있습니다.

08복구와 안전 동작

ADC offline 전환 조건

  • SPI 오류가 한 실행 주기에서 4회 이상
  • CRC 오류가 16 frame 연속
  • 정상 frame 진행이 500 ms 동안 없음

Offline 전환 시 ADC를 정지하고 측정 유효 상태를 해제합니다.

안전 출력과 재시도

  • AFE fault 또는 ADC offline → DAC code 32768
  • ADC offline → 1초마다 초기화 재시도
  • 복구 성공 → IIR filter 초기화 후 새 측정 시작
  • LAN 단선 → 측정/DAC는 계속 실행, 전송만 보류

LED 의미

LED동작의미
● GreenADC/DAC 초기화 성공 시 ON, ADC offline 시 OFF측정 계통 가용성
● Yellow100 ms telemetry 주기마다 toggleApplication Thread heartbeat
● RedAFE fault, ADC offline, DAC error 중 하나면 ON측정/출력 장애. LAN 오류만으로는 켜지지 않음

  1. 보드 Ethernet을 DHCP router 또는 switch에 연결합니다.
  2. PC 방화벽에서 UDP destination port 5000 수신을 허용합니다.
  3. PC에서 monitor를 먼저 실행하고 펌웨어를 reset합니다.
  4. Yellow LED가 약 10 Hz telemetry 기준으로 toggle되는지 확인합니다.
  5. CSV line 또는 Binary decoded line의 source IP, sequence, flags를 확인합니다.

검증 체크리스트

  • DHCP lease 및 보드 IPv4 확인
  • 10 Hz UDP datagram 수신
  • sequence 증가와 timestamp 진행
  • 정상 시 flags에 VALID 포함
  • LAN 케이블 제거 시 측정/DAC 지속
  • 재연결 후 UDP 송신 재개
  • UART COM1과 LAN 값 일치
  • Binary CRC와 length 64 확인
브로드캐스트 수신이 보이지 않을 때 PC 방화벽, Wi-Fi AP의 client isolation, VLAN 경계, managed switch의 broadcast 정책을 먼저 확인하십시오. 운용 환경에서는 수신 서버의 고정 IP로 unicast하는 구성이 더 예측 가능합니다.
